    Prinsip Desain Personal Skill Atlas (10 Core Domains · Basic → Advanced → Sage)
    
          
    
            “Kemampuan nyata di atas angka; bukti di atas perasaan; perkembangan di atas kesempurnaan.” Setiap Core Domain terbagi menjadi Cabang (Branch) dengan 3 jenjang kompleksitas: Tier 1 · Basic → Tier 2 · Advanced (terbuka saat Basic ≥ 3/5) → Tier 3 · Sage (terbuka saat Advanced ≥ 4/5 & prasyarat lintas cabang terpenuhi).
          
    
        
    

        
    
          
    4 Passive Skills Lintas Domain
    
          
    
            
    
              
    1. Self-Management
    
              
    Awareness → Habit Design → Self-Regulation
    
              
    Bukti: Log prioritas, konsistensi, dan review waktu/energi.
    
            
    
            
    
              
    2. Learning How to Learn
    
              
    Imitation → Deliberate Practice → Meta-Learning
    
              
    Bukti: Rencana latihan spesifik, feedback loop, retrieval & transfer.
    
            
    
            
    
              
    3. Ethics & Character
    
              
    Compliance → Ethical Reasoning → Integrity
    
              
    Bukti: Analisis dilema, penjelasan trade-off, konsistensi nilai.
    
            
    
            
    
              
    4. Integrative Thinking
    
              
    Combination → Systems Integration → Creative Synthesis
    
              
    Bukti: Proyek lintas domain untuk menyelesaikan kebutuhan nyata.

    Kamus Istilah Penting
    
          
    
            
    
              
    WPDA (Kategori #01)
    
              
    Singkatan dari Waktu Pribadi dengan Allah — ruang refleksi kerohanian, jurnal Alkitab, pelayanan ibadah, dan berbagi firman.
    
            
    
            
    
              
    Belum Dinilai (Unassessed / NULL)
    
              
    Artinya kamu belum memilih tingkat penguasaan. Ini bukan level 0 atau tidak mampu—hanya belum kamu nilai.
    
            
    
            
    
              
    Capabilities (Kemampuan)
    
              
    Daftar sub-kemampuan inti pada kategori tersebut beserta catatan pengalaman praktis yang sudah kamu pelajari.
    
            
    
            
    
              
    Evidence (Bukti Karya / Relics)
    
              
    Dokumentasi karya, proyek, foto, PDF, atau tautan nyata. Menambah bukti karya tidak mengubah level secara otomatis.
    
            
    
            
    
              
    Meaning (Makna Personal)
    
              
    Cerita reflektif mengapa kemampuan ini penting dalam perjalanan hidupmu.
    
            
    
            
    
              
    Potential (Arah Berikutnya)
    
              
    Ide atau peluang eksplorasi ke depan yang ingin kamu coba tanpa paksaan deadline.
